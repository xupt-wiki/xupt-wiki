# 贡献指南

加入西邮 Wiki 项目组（QQ 群：924632788）

## 贡献方式

我们欢迎通过任何方式对本 Wiki 进行贡献，包括但不限于：

- 为本 Wiki 提供完善的段落
- 以文档文件形式为本 Wiki 添加新页面
- 通过 GitHub 为本 Wiki 提交 Pull Request

## 贡献要求

- 文字排版符合 [中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines/blob/master/README.zh-Hans.md)
- 文本内容真实、适宜传播
- 主题围绕西邮相关内容
- 协议为 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)


## 文章日期与作者

Front matter 中的 `date` 为创建日期，后续修改时保留；只有内容更新时才手动维护 `lastUpdated`，两者都使用 `YYYY-MM-DD`。新增、删除或修正正文信息、文字勘误、措辞修改及有效资料链接修复计入更新；纯排版、元数据、文件移动和等价组件替换不计。新文章只填 `date`，未填写 `lastUpdated` 时不显示更新时间，也不进入“最近更新”。构建不会自动从 Git 生成日期。

文章引用的实验室、博客、群列表等 JSON 数据或组件中的实际内容变化时，也需要同步更新对应文章的 `lastUpdated`。

`author` 使用 GitHub 用户名数组，保留原作者并补充实际内容贡献者。转载文章应保留原作者署名。`docs/.vitepress/data/members.json` 是项目组成员资料，不应仅因提交过 PR 就把贡献者列为项目组成员。
